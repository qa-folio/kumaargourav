Sample Test Artifacts

What my validation work actually looks like.

Illustrative SQL checks on dummy data — the kind of backend validation I run to catch data issues before they reach production.

interest_calculation_check.sqlSQL Server
-- Flag loans where displayed EMI doesn't match recalculated EMI
SELECT loan_id, customer_id, principal_amount, interest_rate, tenure_months,
       displayed_emi, calculated_emi
FROM loan_master
WHERE ABS(displayed_emi - calculated_emi) > 0.01
ORDER BY loan_id;
duplicate_kyc_check.sqlSQL Server
-- Find customers with more than one KYC record (AML risk)
SELECT customer_id, COUNT(*) AS kyc_records
FROM kyc_verification
GROUP BY customer_id
HAVING COUNT(*) > 1;
npa_audit_check.sqlSQL Server
-- Cross-check NPA classification against 90+ days overdue rule
SELECT loan_id, days_overdue, npa_flag
FROM loan_repayment_status
WHERE (days_overdue >= 90 AND npa_flag = 'N')
    OR (days_overdue < 90 AND npa_flag = 'Y');
